# Эвакуация — расчёты и планирование (ASP.NET Core Web API)

Прототип для **Пункта №7** ТЗ по ГО: «Расчёты и планирование эвакуации» —
автоматизация раздела «Эвакуационные мероприятия» Плана ГО:

| Требование ТЗ                                   | Что реализовано                                                        |
|-------------------------------------------------|-------------------------------------------------------------------------|
| Расчётные таблицы: сотрудники (всего / в смене) | `GET /api/evacuation/summary` + вкладка «Расчёты и план»                |
| Транспортная ведомость (свой + по договорам)    | `/api/vehicles`, поле `ownership`, срок договора, исправность           |
| Маршруты в загородную зону, карты в электронном виде | `/api/routes` + загрузка PDF/PNG/JPG карты на маршрут              |
| Приёмный пункт (ППЭ): адреса, контакты          | `/api/reception-points`                                                 |
| Планирование                                    | автораспределение людей по транспорту и пунктам, ручные назначения      |

## Стек
- ASP.NET Core 8 Web API (controllers)
- Entity Framework Core + SQLite (файл `evacuation.db` создаётся автоматически)
- Swagger UI
- Фронтенд на чистом HTML/CSS/JS в `wwwroot/`

## Архитектура
```
Controller  →  Service (интерфейс)  →  Repository (интерфейс)  →  AppDbContext → SQLite
```
Как и в SizCardApi: контроллер знает только сервис, сервис — только репозиторий; всё
регистрируется через `AddScoped` в `Program.cs`. Расчёты (`EvacuationPlanningService`)
работают на списках из репозиториев, без обращения к EF — их легко тестировать с mock-репозиториями.
Файлы карт хранятся в папке `RouteMaps/` через `IMapFileStorage`.

## Как запустить
Нужен **.NET 8 SDK**.
```bash
cd EvacuationApi
dotnet restore
dotnet run
```
- `http://localhost:5000/` — страница (вкладки: расчёты, сотрудники, транспорт, маршруты, пункты)
- `http://localhost:5000/swagger` — Swagger UI

При первом запуске загружаются демо-данные (отключить: `"SeedDemoData": false` в `appsettings.json`).
Чтобы начать с чистой базы — удалите `evacuation.db` и папку `RouteMaps/`.

## Эндпоинты
| Метод  | Путь                                  | Что делает                                              |
|--------|---------------------------------------|---------------------------------------------------------|
| GET/POST/PUT/DELETE | `/api/employees[/{id}]`  | Сотрудники (`?shift=2`, `?subjectOnly=true`)            |
| PATCH  | `/api/employees/{id}/assignment`      | Ручное назначение в транспорт / пункт (с проверкой мест) |
| GET/POST/PUT/DELETE | `/api/vehicles[/{id}]`   | Транспортная ведомость (`?ownership=Own\|Contracted`)    |
| GET/POST/PUT/DELETE | `/api/routes[/{id}]`     | Маршруты                                                |
| POST   | `/api/routes/{id}/map`                | Загрузить карту (form-data, поле `file`; PDF/PNG/JPG ≤ 10 МБ) |
| GET    | `/api/routes/{id}/map`                | Открыть карту                                           |
| DELETE | `/api/routes/{id}/map`                | Удалить карту                                           |
| GET/POST/PUT/DELETE | `/api/reception-points[/{id}]` | Пункты временного размещения                      |
| GET    | `/api/evacuation/summary`             | Расчётные таблицы, дефициты, предупреждения             |
| GET    | `/api/evacuation/plan`                | Текущий план                                            |
| POST   | `/api/evacuation/plan/auto?shift=N`   | Автораспределение (без `shift` — все смены)             |
| DELETE | `/api/evacuation/plan`                | Сбросить все назначения                                 |

## Правила расчёта
- **Подлежит эвакуации** — `isSubjectToEvacuation = true`. Остальные (дежурный персонал) остаются на объекте.
- **Транспорт учитывается**, если он исправен (`Ready`) и (для привлечённого) договор не истёк
  (`contractValidUntil` не указан — договор бессрочный).
- Дефицит транспорта = подлежат эвакуации − места в доступном транспорте; **рейсы** = ⌈люди / места⌉;
  также считается минимальное число машин для вывоза за один рейс.
- Дефицит размещения = подлежат эвакуации − суммарная вместимость пунктов.
- По каждой смене дефициты считаются отдельно (сценарий «эвакуируется только эта смена»).
- **Автораспределение:** маломобильные — первыми; далее по смене и подразделению (коллеги вместе).
  Сначала заполняется собственный транспорт (самый вместительный первым), затем привлечённый;
  пункты размещения заполняются по порядку. Прежние назначения сбрасываются.
- Бизнес-правила: у привлечённого транспорта обязателен поставщик; нельзя уменьшить вместимость
  ниже уже назначенных людей; нельзя назначить в недоступный или заполненный транспорт / пункт.

## Пример (создание маршрута)
```bash
curl -X POST http://localhost:5000/api/routes \
  -H "Content-Type: application/json" \
  -d '{"name":"Основной: объект → п. Лесной","kind":"Main","startPoint":"ул. Музейная, 1",
       "receptionPointId":1,"distanceKm":38.5,"travelTimeMinutes":55}'

curl -X POST http://localhost:5000/api/routes/1/map -F "file=@route.pdf"
```
